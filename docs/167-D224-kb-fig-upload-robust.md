# D224：题库编辑器「选图」链路加固（仍无法更换/无反应）

> 日期：2026-11-23
> 状态：**已完成（2026-11-23）**
> 关联：`docs/166-D223`（img_path 未更新）、`docs/164-D221`（kb 路径识别）
>
> 隐私：无学生数据。

---

## 0. 现场（D223 之后）

教师反馈：📷 选图**仍不正常**；但**手动改 `img_path` 文本似乎可用**。

→ 说明“按路径查素材”的渲染链路是通的，问题在**选图这一步**（弹窗/读取/存储/刷新）。

## 1. 排查到的隐患（逐条加固）

### A. `input` 是游离节点

```ts
const input = document.createElement('input')
input.click()          // 未挂到 DOM
```

部分浏览器/环境下，游离 `<input type=file>` 可能不弹窗或不触发 `change` →
`await` 永不 resolve → 按钮“点了没反应”。

**修复**：先 `appendChild`，用后 `remove()`。

### B. 用户取消时 Promise 永久挂起

只监听 `change`；用户点「取消」时不触发 → 函数挂起。

**修复**：

- 监听 `cancel`（Chrome 113+）；
- 加 120s 超时兜底；
- 取消时明确提示「已取消选择图片（未做任何修改）」。

### C. 存图后没有校验

`persistFigAsset()` 写 localStorage 失败会被静默 catch（配额/隐私模式），
内存里可能有、落盘没有；下次刷新图就丢了。

**修复**：写后立即校验 `settings.figAssets[file.name]`，失败给出可读错误
（提示压缩图片后重试）。

### D. 同名覆盖时缩略图不刷新

`img_path` 不变（同名文件被覆盖）→ `<img src>` 值相同 → 浏览器不重绘。

**修复**：新增 `figRev` 计数，模板 `<img :key="`${r.img_path}#${figRev}`">`，
每次选图后 `figRev++` 强制刷新。

### E. 没有“清除题图”入口

换图失败时教师无法先清空再重选。

**修复**：`img_path` 非空时显示「✕」按钮，清除该行 `img_path`
（**不删除素材文件**，便于重新选回）。

## 2. 状态提示（便于下次定位）

选图完成后状态栏会写清三件事：

```
题图 xxx.png 已入库（img_path=fig/xxx.png；原 fig/yyy.png 已替换；缩略图已刷新）｜已写回 kb/fig/xxx.png
```

- `缩略图已刷新` = `figAssets[文件名]` 命中（渲染链路正常）；
- `缩略图未命中` = 存图或文件名匹配有问题；
- 写回路径按 D221 的自动识别（连 `kb` 目录时写 `fig/…`，不再 `kb/kb/fig`）。
