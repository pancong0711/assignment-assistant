## 0. 现场（两件事）

1. 作业纸预览里，**部分第 1 题**（题干含 `$$…$$` 公式）与**第 2 题**（translation 题）
   仍出现“题号后另起一行”；
2. `class_sheet_json` 导出文件名只有日期（`class-sheet-2026-11-23.json`），
   同一天导出多个班级会**互相覆盖**。

## 1. 题号换行：根因不止软换行

D222 修了「题干含软换行 → `<br>` 被当块级」。但还有一类情况：

`renderRichInline()` 原来**只处理首块是 `<p>`** 的题干；
若首块是下面这些，会直接返回块级 HTML → 题号独占一行：

| 题干形态 | 渲染结果 | 说明 |
|---|---|---|
| `- 句子1\n- 句子2` | `<ul><li>…` | **translation 题常见**（分行句子） |
| `1. 句子1\n2. 句子2` | `<ol><li>…` | 同上 |
| `<div>…</div>` | `<div>` | 富文本粘贴 |
| `> 引用…` | `<blockquote><p>…` | 引用块 |

（`$$…$$` 本身渲染成 `<p>$$…$$</p>`，通常是**同一格里的其他块**导致整体块级化。）

## 2. 修复：行内化规则扩展（PWA 与引擎双端一致）

`app/src/lib/richdoc.ts` 与 `engine/src/assist/paper/richdoc.py`：

| 首块 | 处理 |
|---|---|
| `<p>`（内部仅行内，含 `<br>`） | 去包裹（题号 + 首行同排） |
| 多段 | 只行内化**第一段**，其余保持块级 |
| `<div>`（内部仅行内） | 去掉这层 div |
| `<ul>` / `<ol>` | 各 `<li>` 用 `<br>` 连接（题号 + 第一项同排） |
| `<blockquote>` | 取第一段文字行内化 |
| `<table>` / `<svg>` / `<pre>` | **保持块级**（不能行内化） |

## 3. 导出文件名：班级名 + 完整时间戳

`RosterView.vue`：

```ts
exportStamp()      // YYYYMMDD-HHMMSS（到秒）
exportClassLabel() // 当前班级名，去掉 Windows 非法字符
```

- sidecar JSON：`class-sheet-<班级>-<YYYYMMDD-HHMMSS>.json`
- 整班 HTML：`class-sheet-preview-<班级>-<YYYYMMDD-HHMMSS>.html`

旧命名 `class-sheet-<YYYY-MM-DD>.json`（仅日期）在“同一天导出多个班级”时会覆盖，
现在不会。

## 6. 仍需注意

- 若题干本身就是**表格/SVG**，题号无法与内容同排（块级语义），属预期；
- 题干里若有多段，只有**第一段**与题号同排，其余段落仍换行。
