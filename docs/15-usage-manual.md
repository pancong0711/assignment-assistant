# D96 任务需求单：发布作业「作业来源课程」+ 跨课程复制 + 发布反馈修复

> 日期：2026-10-17
> 状态：**完成**（V1 实测平台不支持跨课程复制 → 方案 A：跨课程明确提示；V3 来源课程下拉、V4 反馈修复、V5 文档均完成）。验证：engine pytest 388 passed / PWA build+selfcheck / 脱敏全绿。
> 关联：`docs/48-D95`（多班发布）、`docs/24-D73`（作业库/发布）、`docs/31-D79`；
> engine `xxt/work.py`（`list_works`/`list_folders`/`copy_work`/`publish_work`）、`serve.py`、PWA `PublishView.vue`。

## 1. 问题查证（2026-10-17）

| # | 现象 | 根因 |
|---|---|---|
| Q1 | 点「发布作业」**无反应**（按钮不灰、无弹窗） | 勾选**跨课程多班**时命中守卫 `courses.size>1 → msg 提示后 return`（仅小 hint，且 `busy` 在守卫之后才置位）→ 观感"没反应" |
| Q2 | 作业库/文件夹选错（跨课程） | 作业库根目录由 **`(courseId, cpi)`** 定位（cpi 班级级）；之前用"第一个勾选班"隐式决定 → 跨课程会选错 |
| Q3 | 跨课程发布不可行 | `publish_work` 用 `courseid + workLibraryId`，workId **属特定课程**，不能跨课程发布 → 需在目标课程**新建/复制** |

## 2. 拍板结论

1. **作业库 = 课程级**（同课程共享一份作业库；不同课程不同根目录）；发布作业**限同课程**；
2. 发布作业卡新增「**作业来源课程**」下拉：列出当前勾选班涉及的课程，显式决定作业库/文件夹/作业列表的 `(courseId, cpi)`（用一个代表班的 cpi）；
3. 新增「**复制到其他课程作业库**」：在「已有作业」行后加 **两个下拉（目标课程 / 目标文件夹）+ 一个按钮**，把当前作业复制到目标课程的指定文件夹；
4. **发布反馈修复**：守卫失败 → **醒目提示**（红字消息 + 日志面板）且 `busy` 前置；跨课程选中时明确提示"发布限同课程，请用「复制到其他课程」"。

## 3. 设计

### 3.1 「作业来源课程」下拉（Q2）
- 选项 = 当前「目标班级」勾选涉及的所有课程（去重）；
- 变更时重载：`list_folders` / `list_works`（用所选课程的代表班 cpi）；
- "目标班级"勾选与"来源课程"**联动**：切换来源课程 → 目标班级限制在该课程（发布限同课程）。

### 3.2 「复制到其他课程作业库」（Q3）
- UI：已有作业行后 → **目标课程下拉** + **目标文件夹下拉** + 「📄 复制到该课程」按钮；
- 引擎：`copy_work(storage, target_course, target_class, target_cpi, target_directory, source_work_id, new_title)` —— **需实测平台是否支持"跨课程复制"**：
  - 若支持：直接复制（新 workId 落在目标课程作业库）；
  - 若**不支持**：退化为"**读源作业内容 → 在目标课程新建草稿**"（题干/附件搬运；如失真则提示）；
- 复制后：目标课程作业库出现新条目（供在该课程发布）。

### 3.3 发布反馈修复（Q1）
- `publishWork`：`busy=true` 之前不再静默；守卫失败 → `msg`（醒目样式）+ 追加日志行；
- 跨课程勾选时，按钮旁显示"发布限同课程；跨课程请用「复制到其他课程」"。

## 5. 真机验证（本单内）
- 在「大学物理知识点拾遗」（课程 `217801417`）与其**另一门课程**之间验证「复制到其他课程作业库」是否成功（确认平台是否支持跨课程复制）；
- 记录结论（支持→直接用；不支持→内容搬运降级）。

## 5bis. V1 真机实测结论（2026-10-17）

- **跨课程复制 = 平台不支持**：`copy_work(target_course=238525833, workId=<217801417 的作业>)`
  返回 `ok:false`、`newWorkLibraryId=""`；目标课程作业数 **12→12 不变**。
  → 平台 `/work/library/copy?courseid=B&workid=<A的workid>` **不生效**（workId 属课程，不可跨课程复制）。
- **内容搬运也不可行**：`work_detail` 读源作业 `stemHtml` 为空（题目为富文本/图片），
  **无法可靠提取题干/附件** → "读源→目标课程新建"会**严重失真**。
- **结论**：D96-Q3 的「复制到其他课程作业库」**无法按原设想实现**（平台约束）。
  需要与用户重新讨论替代方案（见下）。

## 5ter. 拍板：方案 A（2026-10-17）

- **跨课程复制不做**（平台不支持）；跨课程时 UI **明确提示**：
  "作业库按课程独立，无法跨课程复制；请到目标课程重新上传/新建该作业。"
- **保留**同课程「创建副本（副本+时间戳）」（现有 `copy_work`）。
- **发布作业限同课程**（不变）；发布卡加「作业来源课程」下拉。
- **发布反馈修复**：守卫失败醒目提示（不再"无反应"）。

# 2026-10-17 · 发布作业：作业来源课程 / 跨课程说明（D96）

- **作业库按课程独立**（不同课程不同作业库根目录/文件夹）。「发布-学习通 → 发布作业」新增**「作业来源课程」**下拉，
  决定从哪个课程的作业库取**文件夹/作业列表**（随勾选的目标班级联动）。
- **发布作业限同课程**：目标班级必须与「作业来源课程」同一课程；勾选跨课程会**醒目提示**（不再"点了没反应"）。
- **跨课程不可复制**（平台限制）：同一作业无法直接发布/复制到其他课程；请到**目标课程**重新上传/新建该作业后再发布。
  同课程「创建副本（副本+时间戳）」仍可用。

# 2026-10-17 · 发布作业时间/题干缓存/已发布判定（D97）

- **默认时间**：开始 = **现在 + 5 分钟**，截止 = **现在 + 5 天**（PWA 与 CLI 一致），避免"开始时间早于当前"被平台拒。
- **题干**：读取后**缓存在本浏览器**（按作业），下次选同一作业**立即显示**（随后后台刷新），不再每次等"题干未读取到"。
- **已发布判定**：改为**逐目标班**判定——作业下拉标注"（已发布 X/Y 班）"；发布时**自动跳过已发布的班**，
  只对未发布班发布并提示；**全部班**都已发才禁止。
