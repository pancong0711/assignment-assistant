## 2. 与本项目的数据结构映射

| 2508 概念 | 2609 对应 | 一致性 |

## 3. 口径差异（整合时必须定）

## 4. 迁移建议（不重开发）

### 4.1 直接移植（去掉 pandas）

`keypoints.py` 的四个**纯函数**改为吃本项目数据结构：

```
occurrence_prob(entries)          # entries: [{qid, terms[], score, max_score}]
cooccurrence(entries, n)          # 输出 组合/共现次数/共现率/归一化关联
keypoint_loss_gain(entries)       # 输出 考点/覆盖题数/Σ满分/平均失分/失分率/得分率
cooccurrence_share(entries, n)    # 输出 组合/出现题数/组合份额/富集倍数
```

放 `engine/src/assist/grading/keypoints.py`（新文件），**零第三方依赖**（引擎"去 pandas"原则）。

### 4.2 词表升级

`knowledge-terms.json` 的 term 增加：

```json
{"term": "动量守恒", "aliases": ["动量守恒定律", "动量守恒律"],
 "chapter": "chap04", "topic": "…", "tags": ["模型"], "source": "human"}
```

- `synonyms` 直接映射到 `aliases`（2508 → 2609）；
- `tags` 新增字段；
- `split_terms` 增加**同义词归一**（读到 `aliases` 就换成 `term`）。

### 4.3 报告新增两块

`teacher_report` 增加：
1. **知识点共现网络**（含归一化关联 + 富集倍数，2/3 元）；
2. **知识点失分率排行**（满分加权，红高绿低）。

### 4.4 不做
- 不移植 matplotlib 可视化（PWA 用 SVG/前端画）；
- 不移植 docx 报告管线（我们是 HTML/PDF）；
- 不移植 `marks.py` 的试卷解析（那是另一条业务线）。
