## 1. 已确认根因的缺陷

### 1.1 🔴 P0：带间隔号的姓名无法批阅

**现象**

```
❌ AI 批阅失败：assist.grading.items.ItemsError:
   第 45 条 id 非法（1..80 字符，禁路径分隔符）：'阿丽古丽·玉苏甫'
```

**根因**（`grading/items.py:27`）

```python
_ID_RE = re.compile(r"^[0-9A-Za-z_\-\u4e00-\u9fff.]{1,80}$")
```

白名单**缺间隔号 `·`（U+00B7）**。维吾尔族等民族姓名普遍使用间隔号，
俄式姓名（`阿·谢·普希金`）同理。

**影响**：任何带间隔号的姓名**无法批阅**——高危，且报错信息只说"id 非法"，
教师不知道是名字的问题。

**修复**

1. 白名单补充：`·`（U+00B7）、`•`（U+2022）、`・`（U+30FB）；
2. 报错信息改为**可操作**：指出"名字里含特殊字符 X，已允许"或"仍非法，请改名"；
3. 加测试：真实民族姓名 / 俄式姓名 / 带括号姓名都能通过。

### 1.2 🔴 P0：题库编辑器「重新加载」后页面卡死

**现象**：点「🔄 从引擎重载题库」后页面卡住；其它选项卡正常。

**根因**（`stores/kb.ts` `adoptEngineKb`）

```ts
this.books = next            // 整体替换**所有**题库
this.persist()              // 同步写 localStorage
```

题库大（数千行）时：Vue 响应式重建整棵树 + 同步写 localStorage，
**阻塞主线程**数秒到数十秒。

**连带**：教师以为"知识点没写进去"（其实写成功了，只是页面卡住看不到）。
→ 问题 1.3 是它的表象。

**修复**

1. **只替换当前 kind**（其它 kind 不动）——大部分场景只看一个题库；
2. 大题库（> N 行）分批写入（`requestIdleCallback` / 分片 `setTimeout`）；
3. `persist()` 防抖，不阻塞渲染；
4. 完成后给出「已载入 N 题」的明确反馈。

### 1.3 知识点在题库编辑器看不到

**结论**：**不是独立缺陷**，是 1.2 的后果。
AI 作答已成功写回 `related`（教师确认过），只是重载卡住导致看不到。
修好 1.2 即解决。

> 但需补一条验证：AI 作答时勾选「同时标注知识点」后，
> `related` 是否真的写进了 xlsx（用自动化测试锁定）。

### 1.4 🟠 P1：逐生审核改分数后界面不变

**现象**：人工改了分数 → 点保存 → **界面分数没变**（不是"重开变回去"）。

**根因**（`StudentReviewModal.vue`）

```ts
// 保存成功 → emit('saved')
if (r?.ok) { emit('notify', ...); emit('saved') }
```

父组件 `@saved="loadStudents"` → 重新拉草稿 → 弹窗 `props.drafts` 变化 →
`watch` 执行：

```ts
score.value = d?.human?.score ?? d?.ai?.score ?? '100'
```

**把教师刚输入的值覆盖回旧值**。数据其实**已保存**（后端有），但界面被重置，
教师会以为"没生效而反复点"。

**修复**：保存成功后**不要重置编辑态**；
只在"切换学生"或"外部确实变了"时才回填（用 `dirty` 标记保护）。

### 1.5 🔴 P1：发布仍提示「已发布」，单班/多班都一样

**现象**：目标班从未发布过，但提示「已发布禁止重新发布」；
**单班、多班都复现**。

**根因（新发现）**：D165 只改了 URL（补 `clazzid`）和"逐班循环"，但
**逐班循环里拿到的数据仍是全课程的**：

```python
pub = published_library_ids(storage, course_id, cid, str(cpi))
#   → list_class_works(storage, course_id, class_id, cpi)
```

若平台接口**只按 `courseid` 过滤**（`class_id` 参数不生效），
那么每个 `cid` 查到的都是**同一份全课程已发布列表** →
"逐班校验"是**假逐班**，必然把所有班都判成"已发布"。

这与"单班也报错"的现象**完全吻合**。

**修复**

1. 取回已发布列表后，**按每条记录的 `clazzid` 字段自行过滤**（不信任服务端过滤）；
2. 若记录里没有 `clazzid`，退化为"无法逐班判定"并**明确说明**（而不是武断判重复）；
3. 失败时把 `pageHint` 一并返回（D165 已有）。

> **待教师提供**：一次失败的完整返回 JSON（含 `pageHint`），用于确认平台返回结构。

### 1.6 🟠 P1：课堂资料「抽取」失败只显示 HTTP 400

**现象**：点「抽取」→「抽取失败：HTTP 400」。

**根因**（`serve.py` `/materials/extract`）

1. 业务失败（无原件/类型不支持）返回 **400**，且 body 里有 `errors[]`，
   但前端**没展示 body**，只显示了状态码；
2. 用 400 表达"状态不满足"本身也不妥（400 = 请求有问题）。

**修复**

1. 前端：解析 body，展示 `error` / `errors[]`（逐文件原因）；
2. 后端：「没有原件」这类**业务预期**返回 **200 + ok:false**；
   仅参数错误才 400。

### 1.7 🟡 P2：Atopia 最大轮数不可配

**现象**：让 Atopia 整理课堂资料，超过 6 轮中止。

**根因**：`agent.MAX_TURNS = 6` 硬编码；`/atopia/ask` 接受 `maxTurns`
但**前端没有输入框**。

**修复**：Atopia 对话区加「最大轮数」输入（默认 6，上限 20），
并提示"轮数越多越贵"。

### 1.8 🟡 P2：班级页「重算 / 关联 / 写回」顺序与逻辑

**现象**

- 教师先勾选作业包，但**必须再点「写回」才生效**（因为冻结快照在 `recompute()` 里）；
- 关联作业包后，**不能直接预览整班**，还要回作业纸设计页载入包。

**修复**

1. 三个控件排同一行，顺序 **重算 → 关联 → 写回**；
2. **关联后立即冻结快照**（不等写回），并在下拉框**下方显示快照结果**
   （"✅ 已冻结 N 人 / ℹ 快照已存在"）；
3. 整班预览改为**优先用关联的作业包**，无关联才回落 `packStore.currentId`。

## 2. 需要新设计的：抄写题规则

### 2.1 教师诉求（原话）

> 比如我想跳过抄写题的逻辑判断，因为转写过程很可能多模态模型没有准确转写
> 全部内容，造成一定的理解歧义，这样抄写题是不必要判断抄写内容的逻辑的，
> 只要内容跟抄写题目中末尾括号中文字主题一致就好，关键是要抄写一些内容，
> 字数不宜太少，后面我们成功提取教材内容后，这部分的对照也有依据了。

### 2.2 现状 vs 目标

| | 现状 `mode=checklist` | 目标 |
|---|---|---|
| 检查 | 题目/解题过程/示意图**三项是否都抄了** | **主题一致** + **字数下限** |
| 逻辑 | 已声明"不评价推导/计算/逻辑" | 同（保持） |
| 问题 | 转写不准 → "抄了没抄全"会**冤枉学生** | 主题/字数是**鲁棒**判据 |

### 2.3 新规则模式 `topicMatch`

```json
"copy": {
  "mode": "topicMatch",
  "minChars": 80,              // 抄写内容下限（字数太少 = 没抄）
  "topicTolerance": "lenient", // 主题一致性判定宽松度
  "requireDiagram": false,     // 不再要求抄图（转写不可靠）
  "ignoredChecks": ["逻辑", "推导", "公式正确性", "是否抄全三项"]
}
```

**评阅 prompt 改为**：

> 抄写题只做两件事：
> 1. **主题一致**：学生抄写的内容，是否与**题目末尾括号里的主题**相符（不逐字对照）；
> 2. **字数充足**：抄写内容是否达到下限。
>
> **不要**评价：逻辑是否正确、推导是否完整、公式是否正确、是否抄全了题目/过程/图
> —— 转录来自照片识别，细节必然失真，据此判错会冤枉学生。

### 2.4 待定细节

| # | 问题 | 当前假设 |
|---|---|---|
| 1 | `minChars` 固定 80 字，还是按题意长度比例？ | 固定 80，可在规则卡改 |
| 2 | 主题不一致怎么扣？ | 扣 20（与 `irrelevantDeduct` 同口径） |
| 3 | 字数不足怎么扣？ | 分档：< 50% → −10；< 100% → −5 |

## 5. 实施记录（2026-11-05 完成）

### T1 · id 白名单（批次 A）

`_ID_RE` 补充：`·`（U+00B7 间隔号）、`•`（U+2022）、`・`（U+30FB）、`（）()`。
**报错改为可操作**：分别提示「含路径分隔符 X」「过长 N 字符」「含不支持的字符」。

> 顺带发现：报错时机是「第 45 条」，教师根本不知道是哪个学生——
> 现在报错里直接带原始 id。

### T2 · 重载题库不卡（批次 A）

`adoptEngineKb(raw, { onlyKind })`：

- **只替换当前 kind**（教师通常只看一个题库），其它 kind 对象引用不动；
- 新增 `persistDebounced()`：localStorage 写入移出关键路径；
- 重载按钮加 `reloadBusy`（"重载中…"）+ 先让出一帧再重建（避免"点了没反应"）。

> ⚠️ 实施中踩坑：state 声明写的是 `books: KbBook[]`，**运行时实际是
> `Record<kind, KbBook>`**（见 `allBooks` getter）。按声明写数组操作会类型报错 +
> 运行时错。已在注释里标明。

### T3 · 知识点写回验证（批次 A）

从**后端**锁定：`apply_related` 写回后 xlsx 的 `related` 必须真的变了、且留下版本记录；
`read_kb` 要能带回 `related`。教师"看不到"的主因是 T2，这里补上后端证据。

### T4 · 逐生审核分数不再被覆盖（批次 B）

`StudentReviewModal` 的 `watch([idx, drafts])` 会在父组件 `@saved` 重拉草稿后
**把教师刚输入的值覆盖回旧值**（数据其实已保存）。

修复：加 `justSaved` 标记 → 保存后**跳过回填**；切换学生（`idx` 变）时清除标记。

### T5 · 发布重复误判（批次 B）

`published_library_ids()` 增加 `strict` 参数，**按每条记录的 `classId` 自行过滤**
（页面 `viewWork(lib, wid, cid)` 的第 3 个参数本来就取到了，只是没用来过滤）。

`publish_work` 的重复校验改为：
- 记录**带** classId → 只比对本班；
- 记录**不带** classId → 无法逐班判定 → **不武断拒绝**，记 warning 并交给平台结果。

### T6 · 抽取错误可读（批次 B）

- 后端：`/materials/extract` 的业务失败改回 **200 + ok:false**（400 只用于请求非法）；
- 前端：展示 `errors[]` 逐文件原因 + 常见原因提示。

### T7 · 最大轮数可配（批次 C）

Atopia 对话区加「最大轮数」输入（默认 6，上限 20），随 `/atopia/ask` 的 `maxTurns` 透传。

### T8 · 班级页三个按钮（批次 C）

- 同一行、顺序 **重算 → 关联 → 写回**；
- **选择作业包即冻结快照**（`onSnapshotPackChange`），不等写回；
- 快照结果在控件**下方**显示（成功/已存在/失败）；
- 整班预览优先用**关联的包**（`classPreviewPackOverride`），
  `packPadJsons(saved, packIdOverride)` 支持指定包 → 不再要求回设计页切换。

### T9 · 抄写题改为 `topicMatch`（批次 D）

```json
"copy": {"mode": "topicMatch", "minChars": 80, "topicMismatchDeduct": 20,
         "shortRatioDeduct": {"0.5": 10, "1.0": 5},
         "requireDiagram": false,
         "ignoredChecks": ["逻辑","推导","公式正确性","是否抄全题目/过程/图"]}
```

评阅范式与摘要都改了：**只判主题一致 + 字数**；明确写"不要评价逻辑/推导/公式/抄全三项，
转录来自照片识别，据此判错会冤枉学生"。

### 🐞 顺带修一个隐藏很深的问题

`write_rules()` 的合法 mode 校验是**硬编码四元组** →
新增 `topicMatch` 后，**所有** `write_rules` 调用静默失败（返回 ok:false 但调用方没看），
教师改任何规则都存不进去。

修复：抽出 `VALID_MODES` 常量，校验与文档同源。新增模式只改一处。

### T9b · 抄写题字段接入规则卡（补做）

### T10 · 修订版"保存后找不到"（教师第 7 问）

**排查结论**：修订版**其实没丢**——

| 存在哪 | 说明 |
|---|---|
| `grade_store` 草稿库 | `revision.text`，与 ai/human 同一条草稿 |
| 导出报告 | `_mode_report_md()` 会把修订版与 AI 原文**逐行 diff 标红**，kind 标为 `ai-revised` |

**缺的是"能不能看到"**：界面只显示"（已另存修订版，见下）"，
教师不知道它在引擎草稿库（不是本机文件），也不知道怎么回看。

补：
1. 修订版下方加**状态与去向说明**（存在引擎草稿库、导出报告时标红、
   点「编辑修订版」可展开全文）；
2. 未保存时明确提示「本页尚未保存，点保存才会写入引擎」。

> **"保存到本地"按钮名字有误导**：它写的是**引擎草稿库**（`grade-drafts`），
> 不是本机文件。文案已在新提示里说明；按钮名暂不改（避免动到既有习惯），
> 如需要可再改。
