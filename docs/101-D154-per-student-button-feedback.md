# D154 需求单：逐生审核「转写/批阅/完整」按钮反馈修复

> 日期：2026-10-31
> 状态：**已完成**
> 关联：`docs/95-D148`、`docs/12`

## 0. 问题（教师反馈）

> 逐生审核中的转写/批阅/完整三个按键点击没反应，需要选好班级、作业包才行，应该提示一下。

## 1. 根因（两条）

1. **提示写到页面顶部**：`runOne()` 把提示写进 `msg`（页面最上方），
   而教师在页面下方「逐生审核」区操作，**根本看不到**；
2. **未选作业时只写提示就 return**：按钮仍可点、点了没反应。

## 2. 设计

1. **未选中作业/作业包时，三个按钮直接 `disabled`**，`title` 说明原因；
2. 逐生审核区顶部加一行**就地状态条**：说明"需要先在 ③ 区选择作业"；
3. 点击后**行内显示进度**（该行出现 `⏳ 转写中…`），不复用顶部 `msg`；
4. 失败时**行内红字**显示原因（不再只写 `msg`）。

| # | 内容 | 验收 |
|---|---|---|
| T1 | 未选作业 → 按钮 disabled + title + 区顶部提示 | 浏览器 |

## 4. 验收标准

1. 未选作业时按钮不可点，且有明确原因；
2. 点击后**在按钮所在行**能看到进度；
3. 失败原因显示在行内；
4. pytest / build / selfcheck / 脱敏全绿。

## 5. 实施记录（2026-10-31 完成）

根因两条：① 提示写到页面顶部 `msg`，教师在下方逐生区**看不到**；
② 未选作业时只写提示就 `return`，按钮仍可点。

修复：
- 未选作业 → 三个按钮 **disabled**，`title` 说明"请先在 ③ 区选择作业"；
- 点击后**行内**显示 `⏳ 转写中…`（新增 `rowMsg` 按学生名索引）；
- 失败/超时**行内红字**；
- `pollJob` 支持 `rowName`，把进度与结果写回该行。
