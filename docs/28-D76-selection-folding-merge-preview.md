## 背景

教师账号通常跨年度、跨课程有大量班级。原实现存在三类摩擦：

1. 发现课程/班级后默认全选，容易误提取大量无关班级；
2. 课程/班级全部展开，课程一多难以定位；
3. 「提取所选」与「提取账户数据」入口重复；且提取后预览打不开，
   用户误以为必须再点一次全量提取。

## D76-1 · 发现结果默认不选 + 选择记忆

- 课程/班级默认全部不选；作业清单发现结果默认全部不选；
- 课程勾选支持全选/半选/全不选；
- 以 `courseId:classId` / `courseId:classId:workId` 为键写入 localStorage，
  刷新发现后仅恢复仍存在的 ID；新增班级/作业默认不选；
- 文案从「默认全选」改为「默认不选，请按本学期课程勾选」。

实现位置：`app/src/views/XxetongView.vue`（`TARGET_SEL_KEY`、`WORKS_SEL_KEY`）。

## D76-2 · 课程折叠 + 搜索

- 「发现课程/班级」卡内每门课程改为 `<details>`，默认折叠；
- 课程摘要有班级数、已选数；提供「展开全部 / 折叠全部」；
- 支持按课程名、班级名、courseId/classId 搜索；
- 展开状态本机记忆（`xxt-expanded-courses`），不启动浏览器、不触网。

## D76-3 · 提取入口合并

- 主入口保留在「发现课程/班级」：`📥 提取所选（N 个班 / M 份作业）`；
- 「发现作业」结果卡删除「提取账户数据」主按钮，只保留刷新/历史 run/预览等结果操作；
- 全量提取降级为「发现课程/班级」卡内的「高级：全量提取账户数据」折叠项，
  等价 CLI `assist xxt extract --all`，仅在确实需要整账户数据时使用；
- 首次使用流程：发现课程/班级 → 勾选 →（可选）发现作业并勾选作业 → 提取所选。

## D76-4 · 预览数据链修复（关键）

现状存在路径漂移：

- D73-11 起提取存档写入 `pages/runs/<run_id>/v2-review-*.html`；
- `preview.list_review_archives()` 只扫描 `pages/` 与 `xxt-pages/` 根目录；
- 因此正常「提取所选」后 👁 预览找不到存档，被误判为“需要再全量提取”。

修复：

1. `list_review_archives()` 扫描 `pages/runs/*/`（含旧根目录兼容），
   同一 `classId/workId` 按 mtime 取最新；
2. `GET /xxt/preview/students/<classId>/<workId>` 支持 `?run_id=...`，
   PWA 传入当前 run，优先取该 run 的专属存档；
3. 找不到 HTML 存档时回退到已下载的
   `pages/review/<classId>/<workId>/students.json` manifest，
   生成学生列表/分数/状态；
4. 提取成功后 PWA 同步刷新批阅图片索引；错误提示改为
   「先提取所选，或点 ⬇ 下载后再预览」。
