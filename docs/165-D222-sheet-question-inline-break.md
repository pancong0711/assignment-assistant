# D222 修复：作业纸预览中第 2 题「题号独占一行、题干另起一行」

## 0. 现场

作业纸设计的预览里：

- 第 1 题：`1. 题干…`（题号后空一格，正文同行）✅
- 第 2 题：`2.` 之后**另起一行**才写题干 ❌

## 1. 根因

题干渲染走 `renderRichInline()`（去 `<p>` 包裹，让题号与正文同排），
但它把 `<br>` 当成了**块级标签**：

```ts
if (/<(table|ul|ol|li|...|p|br\/?)>/i.test(inner)) return html   // 放弃行内化
```

而 markdown-it 配置了 `breaks: true`：题干里的**一个软换行**（`\n`）
就会被渲染成 `<p>…<br>…</p>`。

于是：**第 2 题的题干在 xlsx 单元格里折了行** → 含 `<br>` → 放弃行内化 →
`<p>` 是块级 → 题号独占一行。

第 1 题没有换行，所以看起来正常。

## 2. 修复（PWA 与引擎两端一致）

`app/src/lib/richdoc.ts` 与 `engine/src/assist/paper/richdoc.py`：

1. **块级判定不再包含 `<br>`**（`<br>` 是行内换行符）；
2. 多段内容 → **只把第一段行内化**，其余段落保持块级：

```
2. 第一段正文…          ← 题号 + 首段同排
第二段正文…             ← 仍按段落换行
```

3. 首块即块级（表格 / SVG / 列表）→ 原样返回。

## 3. 验收

## 5. 说明

- 题干里的**真实换行**（多段）仍会换行，只是题号与**第一行**同排；
- 若希望“整段完全一行”，需要把题干里的换行删掉（编辑题库时把单元格内换行去掉）。
