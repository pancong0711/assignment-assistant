# D235：课堂资料「强制覆盖已有转写」入口

> 日期：2026-11-26
> 状态：已完成
> 关联：D230（独立转写层）、D232（转写提示词）

## 0. 教师问题

课堂资料里 AI 转写完成后，找不到“强制覆盖”勾选入口，无法用新的模型/提示词
重新生成并替换过去的转写内容。

## 1. 现状与根因

引擎 `transcribe_materials(..., force=True)` 已支持忽略已有页并重写
`transcript.json/.md`；但 PWA 的入口不够明确：
- 勾选框藏在文件列表下方，名称“强制重转写”没有说明会覆盖旧内容；
- 「抽取信息 → 转写文本」预览处没有重转写入口，教师看完旧转写后无法直接重做；
- 确认弹窗也没提示本次是复用旧页还是覆盖重写。

## 2. 本次修复

1. 主区域勾选框改名为 **「强制覆盖已有转写（重新调用模型）」**；
2. 执行转写的确认弹窗明确显示：
   - 已勾选：重新调用模型并覆盖旧转写；
   - 未勾选：已有成功页复用，只补缺失页；
3. 「抽取信息 → 转写文本」新增：
   - 「强制覆盖已有转写」复选框；
   - 「🔁 重新转写此文件」按钮；
   - 完成后自动刷新并重新打开当前文件的转写预览；
4. 转写结果提示中注明本次是否按“强制覆盖”重写。

## 3. 引擎语义

`force=True` 时：

```text
忽略已有 transcript 页复用
→ 重新对全部页调用本地 OCR / 视觉模型
→ 覆盖 transcript.json 与 transcript.md
→ 更新 索引.json 中 transcript 元数据
```

`force=False` 时保留原有行为：已有成功页直接复用，仅补缺失页。

## 4. 验收

| # | 场景 | 期望 |
|---|---|---|
| 1 | 已有转写，不勾强制 | 不调用模型，旧内容保留 |
| 2 | 勾选强制并重转写 | 模型重新调用，旧内容被新结果覆盖 |
| 3 | 抽取信息页重转写 | 完成后预览自动刷新为新内容 |
| 4 | 确认弹窗 | 明示本次是否覆盖旧转写 |
