# 实施分组（2026-09-22 · 按相关性聚簇，用户要求整理）

以"改哪部分代码、验证哪条链路"来分组：同域任务一次会话完成，避免来回横跳、
互相踩文件。每批结束都有可验收产物（D1 CLI 超集铁律不变）。

## M-A · 导航骨架与页签重组（一次会话，纯前端）
**内容**：R2.1（Designer 拆"作业纸版式"页 / "作业纸内容"页）+ R2.2 学习通占位卡 +
R2.3 批阅工作台并入学习通 + R2.4 hash 兼容 + R3.1 更名"班级与标签" +

**验收**：7 选项卡导航工作；#/designer 等旧链接跳转正常；学习通卡占位可见；
"打印级 PDF(模板)"语义标注完成。

## M-B · 作业纸保真渲染域（渲染相关聚一炉）
**内容**：R4.1 KaTeX 公式渲染 + R4.2 `assist render --task`（reportlab→pdftoppm
PNG 序列 → serve 端 `GET /render/...?page=`）+ R4.3 PWA 高保真预览翻页（上/下一页
+页码输入+共N页；离线回退 CSS 近似+"近似"角标）+ **B3 fig 题图上传 UI 与引擎写回**
（OPFS→workspace/kb/fig，预览保真同链路）+ R4.1 附带把"LaTeX 源码显示"问题解决。
**为什么和 B3 放一起**：两者都决定"预览/打印到底看到什么图"——题图缺失与公式
不渲染是同一个"保真"语义的两面，engine `render` 通道与题图写回共享联调面。
**验收**：含 $ec{r}=2t\vec{i}$ 的题在预览显示数学公式；在线高保真预览翻页可看
每生页真实渲染；题图从网页上传后任务包引用即可出图。
