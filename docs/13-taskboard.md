## R1 · 一站式环境安装（对应反馈 #1，D25）

**目标**：从"体检报告页"升级为"报告 + 一键修复"，教师尽量只点击、不敲命令。

| 子项 | 内容 | 依赖 |
|---|---|---|
| R1.1 | 静态端软件清单卡：Python/uv/引擎依赖/Playwright 内核/TeX(可选)/中文字体——每项状态+说明+"复制命令"+下载直达链接（Windows/macOS/Linux 分支） | 无（纯前端） |
| R1.2 | `start.bat` / `start.sh` 便携启动脚本入库（自动装 uv→建 .runtime venv→装依赖→起 serve→开浏览器），教师双击即得 Companion 模式 | 阶段5-B5 提前合并 |
| R1.3 | 引擎 `POST /install/{item}` + SSE 进度流（pip 依赖 / playwright install chromium / fonts-download.sh；Python/TeX 无法静默装→返回指引文本给前端展示） | R1.2 |
| R1.4 | 设置中心"体检"页改造：每行红/黄项右侧出现【修复】按钮（在线时走 /install，离线时降级为复制命令） | R1.3 |

**验收**：全新 Windows 机器 → 下载 start.bat → 双击 → 打开 Pages → 体检全绿（除可选 TeX）。

## R4 · 高保真预览与翻页（对应反馈 #5，D27）

| 子项 | 内容 |
|---|---|
| R4.1 | 确认并标注现状差异：CSS 预览≈版式近似；LaTeX 源码原样显示。**新增 KaTeX** 渲染题干中的 $...$ 公式（前端近似显示，打印仍以引擎为准） |
| R4.2 | 引擎 `assist render --task <json> [--student N]`：任务包→reportlab PDF→pdftoppm PNG 序列（本机已验证有 pdftoppm/pdfinfo）；serve 暴露 `GET /render/<task>?page=&token=` |
| R4.3 | PWA "高保真预览"模式（引擎在线时可用）：**上一页/下一页按钮 + 页码输入框 + 共 N 页**，显示引擎真实渲染图；离线回退 CSS 近似并挂"近似预览"角标 |
| R4.4 | "打印级 PDF（模板）"按钮语义注明：输出当前任务包的合成学生样例 PDF（单类型全班统一场景可直接传学习通公告）；整班分层在 R3.5 |

**验收**：一页含 $\vec{r}=2t\vec{i}$ 的题，CSS 预览显示公式（KaTeX）；高保真预览与最终 PDF 像素一致且可翻页。
