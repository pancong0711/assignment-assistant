# D126-B 教师总结报告：易错知识点汇总 + 共现 + 得分率

> 日期：2026-10-30
> 状态：**已实施**
> 关联：`docs/12`（D126-B 登记）、`docs/75-D126`、`docs/78-D130`（`knowledge[]`）、`docs/79-D131`（`knowledge_missing[]`）

## 0. 一句话

面向**教师**的班级/作业总结报告：哪些知识点错得最多、哪些易错点**同时出现**、
哪道题全班都错、哪类题型最薄弱、本章哪些知识点被普遍漏掉。

## 1. 与学生报告的区别（硬边界）

| | 学生报告 | 教师报告（本单） |
|---|---|---|
| 范围 | 一人一份 | 全班/全作业一份 |
| 落盘 | `reports/<学生>.html` | `reports/_teacher_report.md` + `.stats.json` |
| 内容 | 转写 + 评分 + 批语 | 错误分布 + 共现 + 得分率 |
| 去向 | **会上传/发给学生** | **只给教师，不上传**（报告开头明确声明） |
| 是否调 LLM | 否（D127 纯组装） | **否**（纯统计，可复现、免费、可核对） |

## 2. 数据源（全部是已有产物，无需新增采集）

| 字段 | 来源 | 用途 |
|---|---|---|
| `questions[].errors[].knowledge[]` | D127 评阅 schema | 易错知识点来源 |
| `errors[].confidence` | D98-B5 | **low 不计入统计**（与计分口径一致，防幻觉污染清单） |
| `knowledge_missing[]` | D131（summary 题） | 本章遗漏知识点 |
| `per_question_scores[]` | D127 | 逐题得分率 |
| `per_question_rules[].kind` | D130-T3 | 按题目来源/题型聚合 |
| `total_score` / `verdict` / `_manual_review` | D127 | 概览与明细 |

## 3. 分析口径

1. **易错知识点**：按**出错人数**排序；同一学生对同一知识点只计一次
   （否则一个学生多处写错会把它顶到第一，误导讲评）；
2. **共现**：同一份作业里同时出错的知识点对，**至少 2 人**才展示
   （少于 2 人是噪声）；用于判断"是否同一个概念没讲透"；
3. **逐题得分率**：满分按题数分摊（`base = 100 // n`，余数给前几题），
   与 `score_from_analysis` 的均分基线**同口径**；不同学生题数不同 → 取各自满分均值；
4. **题型维度**：按 `per_question_rules[].kind` 统计平均扣分，看哪类题整体弱；
5. **本章遗漏**：`knowledge_missing[]` 计数（D131 清单为依据）；
6. 分数段 + 学生明细（含"顶替嫌疑/需人工"标记——**只给教师看**，D127 已把它从学生报告移除）。

## 4. 产出

- `reports/_teacher_report.md`：人读版（七个章节：概览/易错点/共现/逐题得分率/题型/遗漏/明细）；
- `reports/_teacher_report.stats.json`：机读版，供 PWA 后续画图
  （知识点共现矩阵、得分率柱状图）。

## 5. 入口

- 批阅流程 `report` 步**自动生成**（`flow._run_report`，失败不影响学生报告）；
- 单独重算：`assist teacher-report --task <任务包> [--top 15] [--out DIR]`。

## 6. 实施记录（2026-10-30）

**新增** `engine/src/assist/grading/teacher_report.py`（`load_evaluations` / `analyze` /
`render_md` / `generate`）+ CLI `assist teacher-report` + 接入 `flow._run_report`。

**实施中发现并修掉的 2 个真实缺陷**（均由"喂真实形状数据"暴露）：

1. **`knowledge` 为字符串时被拆成单个汉字**：旧模型偶尔把 `knowledge` 给成
   `"动量守恒"`（而非 `["动量守恒"]`），直接遍历会把 1 个知识点统计成
   "动/量/守/恒" 4 个，共现矩阵全废。已加 `_terms_of()` 统一规范化（兼容
   字符串/list/None，且支持 `，`/`、` 分隔）。
2. **逐题得分率算错**：把"全班总分"当成每题满分，导致 `rate` 出现 **1.43**
   （>100%）。已改为按题数分摊满分（与计分基线同口径），并 `min(1.0, …)` 兜底。

**测试**：`tests/test_d126b_teacher_report.py` **18 例**，覆盖排序/去重/低置信度排除/
共现阈值/满分分摊/题型聚合/遗漏/分数段/渲染/CLI/坏文件跳过/字符串防御/空输入。

**验证**：engine pytest **882 passed**；app build 0 error；selfcheck 21 项全绿；脱敏通过。
