     便于教师一次性检查分层答案。与「打印全部作业纸」按钮并排（细节见 §5.3）。

### R3 参考答案版式：**只有竖版单列**（Q9 拍板简化）

> 用户原话：「我没有完全理解你的分栏困难，因为 latex 里面处理分栏排版不是已经很成熟了吗？哦，你是用的 html 方法，
> 那么要不我们就采用竖版单列好了，这样简单一些，不过你要确定 cli 工具侧也可以实现这样的排版。」

**为什么 HTML 侧分栏难**（补充说明，供理解）：
LaTeX 的 `multicol` 是**排版引擎原生能力**，能在底层把内容流切成等高栏并自动平衡；
而 HTML 的 `column-count` 只在**固定高度容器**内分栏，实测「12 题只排出 10 题、其余被裁掉」，
无法与浏览器分页自然衔接。所以放弃横板双列是**合理简化**，不是退让。

| 项 | 规则 |
|---|---|
| 页面 | A4 **纵向**，单列 |
| 排布 | 一题接一题，**连续排**（不强制每页一题，因为答案可能超过页长） |
| 换题 | **一题答案排完后，新题另起一页**（`break-before: page`） |
| 超高题 | 单题超过一整页 → 允许自然跨页（`break-inside: auto`），该题结束后的新题仍另起一页 |
| 切分 | **题级切分**：只在"题与题之间"分页，**绝不切公式/图/段落** |

**能否保证"不与前一题答案混在一起"**（回答 Q9 追问）：
**能。** 实现方式不是靠"填满页面"，而是**每道题一个卡片 + 强制换页**：

```css
.card { break-inside: avoid;  }        /* 题内尽量不拆（超高时才拆） */
.card + .card { break-before: page; }  /* 一题排完 → 新题另起一页 */
```

实测（Chromium 导出 PDF）：单列 + `break-inside:avoid` 能**完美自然分页**（12 题 → p1 排 7 题、p2 排 5 题），
不会出现题与题交错。加 `break-before: page` 后即实现"一题一页起步、超高才续页"。

**CLI 侧对等（用户明确要求）**：新增 `assist sheet answers`，用**同一个模板/同一份 CSS**（`answer.html.j2`），
与 PWA 共用 `richdoc.render_rich` + 同源 KaTeX，保证 CLI 产出的 PDF/HTML 与网页预览一致；
另提供 `--one-page-per-question`（默认开）与 `--no-page-break`（连排）两个开关。

### R5 修复：SVG 不显示（测量探针）

- 文件：`app/src/lib/measureLayout.ts:59`
- 改：`probe.textContent = text` → `probe.innerHTML = renderRich(text)`
- 连带：探针样式与 `.q-solution`/`.q-content` 对齐（`font-size`、`line-height`、`svg{max-width:100%;height:auto}`），否则量出来仍不准；
- **注意**：作业纸预览（不含答案）仍需测量题干；参考答案预览改为纯 CSS 分页后不再依赖估高，但作业纸预览仍需要准确测量。
- 验收：含 `<svg>` 的题干/答案测量高度与真实渲染误差 < 5%。

### R6 修复：行间公式显示成源码

- 根因：`\[...\]` 与正文同 `<p>`，`nl2br` 插入的 `<br>` 把定界符拆到多个文本节点 → KaTeX 无法匹配。
- 方案：`_protect_math()` 抽出行间公式时，**在占位符前后补空行**（强制独立成段）；
- 验收用例：**必须用用户提供的真实源码**（含 `\begin{cases}` + `\\[2mm]` + `<svg>` + `\boxed`），断言：
  - 4 个行间公式全部渲染（`katex-display` = 4）；
  - 6 个行内公式保持行内（不入 `.katex-display`）；
  - 业务 `<svg>` 正常（227×170）；
  - 无 `katex-error`、无残留 `\[`。

### R7 公式语义保持

- **不得**把所有公式统一成行间；
- 行内 `$..$` / `\(..\)` → 行内渲染（`display:inline`）；
- 行间 `$$..$$` / `\[..\]` → 块级（`.katex-display`，居中、独立成行、可缩放占宽）；
- 新增自检：混合内容断言两类公式的 DOM 与 `computedStyle.display`。
