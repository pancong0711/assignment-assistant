## 2. 需求分解

### R1 参考答案从作业纸预览/打印中分离

| 项 | 内容 |
|---|---|
| 变更 | 「作业纸预览」区**移除**「显示参考答案」开关；预览/打印/下载的作业纸 HTML **固定 `includeSolution=false`** |
| 保留 | 数据层仍保存完整答案（供参考答案预览使用）；`sheetHtml.ts` / `assignment.html.j2` 的 solution 渲染能力**不删** |
| CLI | `assist sheet html` 保留 `--no-solution`；**默认行为是否改为不含答案**见 §5-Q1 |

### R2 新增「参考答案预览」区

- **位置**：`SheetDesignView.vue` 内、`SheetPreviewSection` 之后、`SheetOutputSection` 之前（即「作业纸预览区下方」）；
- **内容**：按当前作业纸 `items` 顺序，逐题输出「题号 + 题干（可选）+ 完整参考答案（md+html 渲染）」；
- **独立 iframe**：与作业纸预览同级（`srcdoc`），**固定高度 560px**，互不影响；提供「🔍 弹窗细看」（复用 `SheetHtmlPreviewModal`）；
- **独立打印**：`🖨 打印参考答案` 按钮 → 打开独立窗口并 `print()`；
- **独立导出**：`⬇ 下载参考答案 HTML`（自包含 KaTeX，离线可开）；
- **版式选择**：`竖版单列` / `横板双列`（见 R3）；
- **选项**：是否显示题干（默认显示，便于对照）、是否显示题号（默认显示）。

### R3 参考答案两种版式（按 Q7 拍板）

| 模式 | 页面 | 排布 | 换题规则 |
|---|---|---|---|
| 竖版单列 | A4 纵向 | 整页 1 列，一题接一题**连续排** | 一题排完（含超高跨页）→ **新题另起一页** |
| 横板双列 | A4 横向 | 每页左右 2 列 | 一题排完 → **新题另起一列**；当页无空列 → **新页第一列** |

**已实测的浏览器排版约束（决定实现方案）**：

| 方案 | 竖版单列 | 横板双列 | 结论 |
|---|---|---|---|
| CSS `column-count` + `column-fill:auto` | 分栏需固定高度，**溢出被裁**（12 题只出 10 题） | 同左 | ❌ 不可用（会丢题） |
| CSS Grid 两列 | — | 能自然分页，但**按行交错**（Q1 左/Q2 右），阅读顺序错乱 | ❌ 顺序不对 |
| 整页 `flex` 两列（各列独立增长） | — | 能分页，但**左右列高度各自溢出**，题目错位（p2 只剩 Q6/Q12） | ❌ 不可控 |
| **单列 + `break-inside:avoid`** | ✅ **完美自然分页** | — | ✅ 竖版采用 |
| **手动分页 + 每页 flex 两列（列内 `break-inside:avoid`）** | — | ✅ 可控、顺序正确（左列排满再右列） | ✅ 横版采用 |

**实现定论**：
- **竖版单列**：纯 HTML 流 + `.answer-card{break-inside:avoid}`，由浏览器自然分页。**零 JS 计算**。
- **横板双列**：需要**每页一个 flex 行（左/右两列）**，并决定"哪些题进哪一列"。
  由于横版一栏高度有限，采用**按"答案估高"贪心分配**：
  1. 逐题估算高度（用 D113-R5 修好的测量探针，`innerHTML` 真实渲染）；
  2. 依次填入当前页左列，放不下则右列，两列都放不下则新页左列；
  3. 单题超过一整栏高 → 独占该栏并允许溢出（`break-inside:auto`），不影响其它题。
- **两道逻辑都只在题级切分，绝不切公式/图**（与 D103 的"段级切分"本质不同）。

> 备注：竖版若某题超过一整页，`break-inside:avoid` 会被浏览器忽略并自然拆分——这正是 Q7 所说"有的题目答案可能超过页面长度"，属可接受行为。

### R4 作业纸预览改单列整行

- `SheetPreviewSection` 根节点去掉 `flex:1 1 520px; min-width:440px`，改为 `width:100%`；
- iframe 高度保持（或按内容自适应，见 §5-Q4）；
- 检查同页其它 `flex-wrap` 容器，确保不再出现并排卡片。

### R5 修复：SVG 不显示（测量探针）

- 文件：`app/src/lib/measureLayout.ts:59`
- 改：`probe.textContent = text` → `probe.innerHTML = renderRich(text)`
- 连带：探针样式与 `.q-solution`/`.q-content` 对齐（`font-size`、`line-height`、`svg{max-width:100%;height:auto}`），否则量出来仍不准；
- **注意**：作业纸预览（不含答案）仍需测量题干；**参考答案预览的横板双列也依赖它**（R3：需按估高分配列）→ 必须修，且修好后 R3 才可靠。
- 验收：含 `<svg>` 的题干/答案测量高度与真实渲染误差 < 5%。

### R6 修复：行间公式显示成源码

- 根因：`\[...\]` 与正文同 `<p>`，`nl2br` 插入的 `<br>` 把定界符拆到多个文本节点 → KaTeX 无法匹配。
- 方案：`_protect_math()` 抽出行间公式时，**在占位符前后补空行**（强制独立成段）；
- 验收用例：**必须用用户提供的真实源码**（含 `\begin{cases}` + `\\[2mm]` + `<svg>` + `\boxed`），断言：
  - 4 个行间公式全部渲染（`katex-display` = 4）；
  - 6 个行内公式保持行内（不入 `.katex-display`）；
  - 业务 `<svg>` 正常（227×170）；
  - 无 `katex-error`、无残留 `\[`。

### R7 公式语义保持

- **不得**把所有公式统一成行间；
- 行内 `$..$` / `\(..\)` → 行内渲染（`display:inline`）；
- 行间 `$$..$$` / `\[..\]` → 块级（`.katex-display`，居中、独立成行、可缩放占宽）；
- 新增自检：混合内容断言两类公式的 DOM 与 `computedStyle.display`。

### 5.2 新增待确认（执行前请拍板）

#### Q9 横板双列的「列分配」需要估高，接受近似吗？
实测表明横版双列**无法**靠纯 CSS 同时满足"左列排满再右列 + 自然跨页"，必须由程序决定"哪些题进哪一列"，
这需要**估算每道答案的高度**（用修好的探针真实渲染后测量）。
- 方案 A（推荐）：**按估高贪心分配**（左列填满 → 右列 → 新页左列）。误差可能导致末列稍空，但不丢内容、不切题。
- 方案 B：**不估高**，固定"每页 N 题"（如每页 4 题：左 2 右 2）。实现最简单，但长答案会溢出栏底。
> 我建议 A：观感更好；估高用的就是 D113-R5 修好的探针，顺带验证它。

#### Q10 参考答案预览的「题号」用哪种编号？
- 方案 A（推荐）：与作业纸一致（`auto` 连续 1./2.，或 `labels` 覆盖值）；
- 方案 B：用题库 id（`chap04-01`），便于教师定位到题库行。
> 我建议 A + 悬浮显示 id。

#### Q11 参考答案预览是否受「分层 tag / 变体」影响？
当前作业纸可能有多张变体（按 tag）。参考答案预览：
- 方案 A（推荐）：**只出当前正在编辑的这张作业纸**的答案；
- 方案 B：出当前作业包里**全部变体**的答案（连排，按变体分节）。
> 若教师需要"一次检查全部分层答案"，B 更有用。请定夺。

#### Q12 作业纸打印是否保留「教师版（含答案）」入口？
R1 让预览/打印不含答案，但**之前可能有人用"含答案"打印教师版讲义**。
- 方案 A（推荐）：作业纸打印**只出学生版**；需要答案时用「参考答案预览」单独打印（两者可订在一起）；
- 方案 B：作业纸输出段保留一个「导出教师版（含答案）」按钮作为兼容入口（不作为预览）。
> 我建议 A（干净），但若你有旧习惯可选 B。
